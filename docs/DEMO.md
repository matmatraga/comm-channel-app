# Recording the demo GIF

Add a short screen recording to showcase OmniComm in the README and your portfolio.

## Suggested flow (30–45 seconds)

1. Open **two browser tabs** logged in as `demo1@omnicomm.app` and `demo2@omnicomm.app` (password: `Demo1234!`).
2. **Chat:** send messages, show typing indicator and read receipts.
3. **Attachment:** send an image, hover download, open lightbox.
4. **Call:** start an audio or video call — callee hears ringtone, accepts, WebRTC connects.
5. **Email:** open inbox, select an email, show HTML rendering on the light reading surface.

## Tools

- [ScreenToGif](https://www.screentogif.com/) (Windows)
- [LICEcap](https://www.cockos.com/licecap/) (macOS/Windows)
- OBS → export as GIF or use a converter

## Save location

Save the file as:

```
docs/demo.gif
```

Then uncomment the GIF line in `README.md`:

```markdown
![OmniComm demo](./docs/demo.gif)
```

Keep the GIF under ~5 MB for GitHub (720p, 15–20 fps is usually enough).
